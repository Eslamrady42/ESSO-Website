ESSO V23 - Gemini + Furnished 3D

AI provider: Gemini only.
Default model: gemini-3.8-flash.
Fallbacks: gemini-3.7-flash, gemini-3.6-flash, gemini-3.5-flash-lite.

Set GEMINI_API_KEY in .env or use setup-gemini.php.
The viewer uses an internal canvas renderer (no external 3D CDN) and adds furniture primitives by room type: reception/living, bedroom, kitchen, bathroom, dining, office, laundry/utility.

This is a preliminary visualization. Furniture is indicative, not a construction document.
